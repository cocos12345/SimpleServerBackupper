# 项目说明
1. 功能: 本项目主要功能为服务器代码本地备份，即将多个Linux远程服务器中的代码自动备份到Windows本地文件夹。  
1. 适用范围: 本项目适用范围主要为小型开发项目以及遗留项目，旨在帮助开发者通过简单且无影响的方式对服务器代码进行备份，以便于回退。 本项目并不适用于中大型生产级项目，此类项目建议使用CI/CD进行部署与回退。  
1. 目标: 本项目目标为尽可能保持简单、便捷、易用。

# 快速上手
1. 在appsettings.json中Hosts一节中配置对应的Linux主机名与用户密码
1. 在BackUpSetting一节中配置本地目录，远程拷贝目录，以及排除目录等
1. 运行程序即可
P.S.:您可以通过添加多个配置文件，对Program.cs中硬编码的文件名进行替换，即可对于多个不同的项目进行备份
